# 개인 여행지 관리 기능 수요 조사

조사일: 2026-10-17

## 조사 요약

개인 여행 관리 서비스의 공통 수요는 단순히 장소를 저장하는 데서 끝나지 않고,
저장한 장소를 **여행별로 묶고, 날짜와 지도에서 확인하며, 비용과 우선순위를
함께 판단하는 것**으로 수렴한다.

- [Google Maps 공식 도움말](https://support.google.com/maps/answer/7280933?hl=en-GB)은
  장소를 사용자 정의 목록으로 묶고, 메모를 남기고, 목록을 공유하는 흐름을 제공한다.
- [Google Maps 장소 관리 도움말](https://support.google.com/maps/answer/9948049?hl=en-AU)은
  저장 장소 검색·필터, 목록 저장, 지도 위치 확인을 핵심 관리 기능으로 안내한다.
- [Wanderlog 공식 도움말](https://help.wanderlog.com/hc/en-us)은 여행 설정, 장소와 목록,
  날짜별 일정, 지도, 예산·비용 관리를 주요 기능 영역으로 구분한다.
- 최근 개인 개발자들의 문제 설명에서도 여행 일정은 메모, 지도, 예산 앱으로 흩어지고
  이를 한 화면에 모으려는 요구가 반복된다. 이는 정량 설문이 아닌 보조적인 정성 신호로
  사용했다.

## 우선순위

### 이번 반영

1. 여행별 장소 묶음: 같은 여행의 장소를 목록처럼 관리한다.
2. 장소 우선순위: `꼭 가기`, `관심`, `나중에`로 의사결정을 돕는다.
3. 예상 비용: 가고 싶은 장소의 비용 합계를 바로 확인한다.
4. 지도 바로가기: 저장한 국가·도시·장소명으로 Google Maps 검색을 연다.
5. 필터와 정렬: 여행별 필터, 방문일·우선순위·비용·저장일 정렬을 제공한다.
6. 상세 일정: 날짜, 시작·종료 시간, 장소, 일정 종류, 비용, 메모를 날짜별로 관리한다.

### 다음 단계 후보

1. 여행 시작일·종료일과 일정 자동 일수 계산
2. 지도 위 전체 장소 표시와 이동 동선 비교
3. 항공·숙소 예약 정보와 준비물 체크리스트
4. 여행 목록 공유와 동행자 공동 편집
5. 다중 통화 지출 기록과 실제 비용 결산

초기 사이드 프로젝트의 구현·운영 난이도를 고려해 외부 지도 API, 파일 업로드,
실시간 공동 편집은 이번 범위에서 제외했다.
